Welcome to the User Management System! 🚀 This repository houses a complete, full-stack web application designed from the ground up to demonstrate industry-ready development skills. Built as a core project milestone, it seamlessly bridges a beautifully crafted frontend with a robust, secure PHP and MySQL backend. From dynamic DOM manipulation to secure database routing, this project is a testament to end-to-end software engineering.

On the surface, the application boasts a visually striking, mobile-first responsive UI crafted with HTML5, CSS3, and Bootstrap 5. 🎨 The aesthetic is driven by a strict, custom 7-color vibrant pastel palette that completely overrides standard framework defaults. To elevate the user experience, a custom vanilla JavaScript engine renders a mathematically randomized, interactive animated bubble background that dynamically reacts to user interactions, proving that pure frontend code can be incredibly engaging.

Under the hood, security is the highest priority. 🔐 The backend architecture is powered by native PHP, utilizing prepared statements to completely neutralize SQL injection threats. User passwords are rigorously protected using industry-standard password_hash() cryptography. Furthermore, a bulletproof Session Management system governs the entire application, ensuring that authenticated states are strictly maintained during login, navigation, and logout sequences.

Once authenticated, users are greeted by a dynamic, personalized dashboard. 🖼️ Here, they have full control over their profile management. The system features a highly secure file-handling protocol, allowing users to upload custom profile pictures. This backend script meticulously validates file extensions (restricting to JPG, PNG, and GIF) and enforces strict 2MB file size limits before safely storing the assets and linking them via the normalized relational database.

Finally, the application features a comprehensive, role-based Admin Control Panel to execute full CRUD (Create, Read, Update, Delete) operations. ⚙️ Administrators are granted elevated privileges to view all registered accounts in a clean, responsive data table. They can seamlessly update user roles—promoting standard users to admins—or securely delete obsolete accounts, all while safety protocols run in the background to prevent accidental self-deletion or administrative demotion.
